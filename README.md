# Student Enrollment Management System

A simple Android application developed for the **Mobile Application Development (MAD) Mid Exam**. This application allows users to manage student enrollment records using SQLite for local data storage.

## Features

- **Add Student**: Add a new student record with their name, student ID, and enrollment status.
- **View Students**: Display saved student records.
- **Edit Student**: Update existing student information.
- **Delete Student**: Remove student records.
- **Enrollment Statistics**: Display the total number of students and enrolled students.
- **Local Database**: Store student records locally using SQLite.

## Technologies Used

- **Programming Language:** Java
- **User Interface:** XML
- **Database:** SQLite
- **Development Environment:** Android Studio

## Student Information

Each student record contains:
- Student Name
- Student ID
- Enrollment Status (Enrolled / Not Enrolled)

## Getting Started

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync and finish loading the project.
4. Run the application on an Android emulator or a connected Android device.

## Database

The application uses SQLite to store student enrollment data locally. Student records can be added, viewed, edited, and deleted through the application interface.
